Un proyecto de Blackjack en JavaScript es una aplicación web interactiva que recrea el clásico juego de cartas ("21") combinando lógica de programación en el cliente con una interfaz gráfica dinámica en HTML5 y CSS3.

Componentes principales del proyecto:

Lógica de juego: Manejo de un mazo de 52 cartas, algoritmo de barajado dinámico (como Fisher-Yates) y cálculo automático del valor de la mano, incluyendo la lógica del As (1 u 11 puntos según convenga).

IA de la banca (Dealer): Automatización del comportamiento del crupier, configurado para pedir cartas automáticamente hasta alcanzar un mínimo de 17 puntos.

Interfaz y manipulación del DOM: Renderizado visual de las cartas, actualización de puntuaciones en tiempo real y botones de acción (Pedir, Plantarse, Doblar o Nueva partida).

Gestión de estado y fichas: Control de turnos, verificación de condiciones de victoria/derrota/empate y actualización del saldo de apuestas del jugador.

Valor educativo:
Es un proyecto fundamental para desarrolladores frontend, ya que permite poner en práctica la manipulación del DOM, el manejo de eventos de usuario, estructuras de datos (arrays/objetos) y 
la modularización del código mediante clases en JavaScript (ej. clases Carta, Mazo y Jugador).
